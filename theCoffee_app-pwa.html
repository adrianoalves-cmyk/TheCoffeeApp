☕ Brew Manager
One-time setup — takes about 3 minutes
⚠️ Google Sheets API keys are read-only. This app uses a free Apps Script Web App instead — it lives inside your Google Sheet and handles all reads and writes securely.
1
Create your Google Sheet
Go to sheets.google.com and create a new blank spreadsheet. Name it anything you like (e.g. "Brew Manager").
2
Add the Apps Script
In your sheet: Extensions → Apps Script.
Delete any existing code, paste the contents of Code.gs (provided separately), then click Save (💾).
3
Deploy as Web App
Click Deploy → New deployment.
• Type: Web app
• Execute as: Me
• Who has access: Anyone
Click Deploy, authorise when prompted, then copy the Web App URL.
4
Paste your Web App URL below
It looks like: https://script.google.com/macros/s/ABC.../exec
Your URL is stored only in this browser. All data lives in your Google Sheet.
